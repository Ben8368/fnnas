# FnNAS 发布与下载 · 小米 10（UMI）

Amlogic、Allwinner 和 Rockchip 的镜像请按 FnNAS 主文档选择。小米 10 使用单独的 ABL v2 Boot、配套 RootFS 和对应刷新率的 UMI 内核。[FnNAS 中文主文档](../../../../README.cn.md)

## 当前状态

默认构建为 CSOT 60 Hz。公开 Release 已有通过 RAM 探针验收的 `6.18.65` CSOT 90 Hz 内核，60 Hz 采用 Actions 候选进入[原生 fnOS 真机验收](./03-自行构建.md#原生-fnos-真机验收)，首启、WebUI、存储和 OTA 分别记录结果。[FnNAS Fork 的 Releases](https://github.com/Ben8368/fnnas/releases)

| 产物 | 位置或名称 | 使用方式 |
|---|---|---|
| UMI 内核候选 | `Build Umi kernel` 的 Actions 构建附件 | 在设备上验证同一版本和 CSOT 档位 |
| 已发布 UMI 内核 | 带源码 SHA 的 `umi-kernel-*` Release 的 `<6.18.x>-qualcomm-sm8250-xiaomi-umi-csot<60或90>.tar.gz` | 由 `renas -b xiaomi-umi kernel query` 或 `kernel fetch` 选取 |
| 本地验收镜像 | `renas -b xiaomi-umi native-acceptance` 输出的 `boot.img`、`rootfs.img`、`SHA256SUMS` 和 `FLASH.md` | 使用同一构建输出，以 Fastboot 写入 `boot` 和 `userdata` 后验收 fnOS |
| 历史 Debian 原始包 | `misaka-link/umi-linux` 的 `v2026-09-27` | 使用旧版流程和该发布的校验值 |

## 构建与发布限制

`Build Umi kernel` 支持 `release`、`csot-60`、`csot-90`、`lab-60`、`lab-90`。其中前三档可打包含 Image、DTB 和同版模块的 UMI 内核候选。源码版本、提交、刷新率和设备验收结果应与候选附件对应。[内核工作流](../../../../.github/workflows/build-kernel.yml) · [真机无刷写验收](./04-真机无刷写验收.md)

[第三阶段运行与验收](./qualcomm-stage3.md#内核真机验收与提升) 描述了不依赖默认分支的本地提升。支持 `-r OWNER/REPO` 指定独立的公开发布仓库。

整理镜像发布时使用同一次构建的 Boot 与 RootFS，附带完整 SHA-256、内核提交、CSOT 档位、文件系统和实际验证范围。许可及来源引用根目录的 [LICENSE](../../../../LICENSE) 与 [NOTICE](../../../../NOTICE.md)。发布正文可使用 [模板](./RELEASE-NOTES.md)。

## 校验本地组装产物

从生成镜像的目录运行以下命令。历史 Debian 包使用其原有的 `SHA256SUMS.txt`。

```bash
cd out/umi-image
sha256sum -c SHA256SUMS
```
